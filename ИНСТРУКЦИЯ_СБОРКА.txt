# Автономная сборка «Поиск по PDF» для Windows 10 x64

Это проект для автоматической сборки одного EXE-файла. В готовый EXE включаются Python-зависимости,
Tesseract OCR и русский языковой файл `rus.traineddata`. На компьютере, где запускается готовый EXE,
ничего дополнительно устанавливать не потребуется.

## Важно
В этой среде нельзя непосредственно запустить Windows-сборщик, поэтому я не могу честно приложить
проверенный `.exe`. Этот проект настроен на сборку в Windows через GitHub Actions.

## Как получить EXE (один раз, потребуется аккаунт GitHub)

1. Откройте https://github.com и войдите в аккаунт (или создайте бесплатный).
2. Создайте новый пустой репозиторий, например `poisk-pdf`.
3. Распакуйте этот ZIP на компьютере.
4. Загрузите в репозиторий все файлы и папки из распакованной папки, включая скрытую папку `.github`.
   На странице репозитория можно выбрать **Add file → Upload files**.
5. Откройте вкладку **Actions**. Выберите workflow **Build Windows EXE** и нажмите **Run workflow**.
   Если сборка запустилась автоматически после загрузки файлов, дождитесь её окончания.
6. Откройте завершённый запуск workflow. Внизу страницы в разделе **Artifacts** скачайте
   `Poisk-po-PDF-Windows10-x64`.
7. Распакуйте скачанный artifact — внутри будет `Поиск_по_PDF.exe`.

## Использование готового EXE

1. Дважды щёлкните `Поиск_по_PDF.exe`.
2. Нажмите «Открыть PDF…» и выберите скан.
3. Нажмите «Распознать текст».
4. Введите слово или часть слова, например «Тобольск».
5. Нажмите на результат слева: справа покажется исходная страница с красной рамкой вокруг слова.

## Примечания

- Первое распознавание занимает время; последующие открытия того же PDF используют локальный кэш.
- Кэш хранится в `%LOCALAPPDATA%\PDFWordSearch\cache`.
- Поиск учитывает варианты `ё/е` и часть дореформенных букв, но OCR старой печати не гарантирует 100% точность.
- Сборка загружает зависимости из интернета только на стороне GitHub Actions. Сам готовый EXE работает офлайн.
- Сборка использует Windows runner GitHub-hosted и публикует EXE как artifact на 30 дней.
